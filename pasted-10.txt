## Lo que falta para un terminal educativo ternario/binario

### 1. REPL ternario interactivo

Un intérprete que evalúe expresiones ternarias en vivo:

```
tritos> 1 + 1
  binario: 10
  ternario: 2
  trits: [+][0]

tritos> 5 * 3
  binario: 1111
  ternario: 120
  trits: [+][-][0]

tritos> -1 + 1
  binario: 0
  ternario: 0
  trits: [0]
```

**Falta**: un parser/evaluador ternario con salida dual.

### 2. Conversor binario ↔ ternario ↔ base 60

Comandos tipo:
```
tritos> conv 255
  binario:   11111111
  ternario:  100110 (5 trits)
  maya:      12.15 (base 20)
  babilonio: 4.15 (base 60)

tritos> conv -t 1-10
  binario:   1011
  decimal:   11
```

**Falta**: implementar conversión entre bases con notación ternaria `-`, `0`, `+`.

### 3. Editor de código ternario

Un editor que permita escribir programas en **ternario** y ejecutarlos:

```
tritos> edit suma.tri

  # Programa ternario: suma de dos trits
  entrada a, b
  resultado = a + b
  salida resultado

tritos> run suma.tri
  a = +1
  b = -1
  resultado = 0
```

**Falta**: un lenguaje ternario mínimo + intérprete.

### 4. Visualizador de operaciones

Que muestre **paso a paso** cómo se hace una operación en binario y en ternario:

```
tritos> suma 5 + 3

  Binario:
    0101
  + 0011
  ------
    1000  = 8

  Ternario:
    +-0+   (5)
  + +0+0   (3)
  --------
    +0+-   (8)
```

**Falta**: visualizador de operaciones bit a bit / trit a trit.

### 5. Compilador de binario a ternario

Que tome un programa en C/binario y lo traduzca a ternario:

```
tritos> compilar hola.c --ternario
  Generando hola.tri...
  Ejecutando...
  Hola mundo (ternario)
```

**Falta**: backend ternario para un compilador (GCC/LLVM modificado o propio).

### 6. Máquina virtual ternaria

Un intérprete de **bytecode ternario**:

```
tritos> vm programa.tbc
  [VM Ternaria v0.1]
  Cargando 120 trits...
  Ejecutando...
  Salida: +0-+0-+0
```

**Falta**: diseño de ISA ternaria + VM.

### 7. Modo comparación binario/ternario

Un comando que ejecute lo mismo en ambos mundos y compare:

```
tritos> comparar suma 5 3
  Binario:  8 (4 bits, 4 operaciones)
  Ternario: 8 (3 trits, 3 operaciones)
  Ahorro:   25% en símbolos
```

**Falta**: benchmark integrado.

### 8. Tutoriales interactivos

Lecciones guiadas dentro del terminal:

```
tritos> tutorial
  [1] Introducción al ternario
  [2] Operaciones básicas
  [3] Conversión binario ↔ ternario
  [4] Lógica ternaria (Kleene)
  [5] Aritmética base 60
  [6] Programación ternaria
  Elige:
```

**Falta**: contenido pedagógico estructurado.

### 9. Historial y modo estudio

Que guarde las sesiones y permita revisarlas:

```
tritos> historial
  1. conv 255
  2. suma 5 3
  3. edit suma.tri
  4. run suma.tri

tritos> guardar sesion1.txt
```

**Falta**: persistencia de sesiones.

### 10. Modo dual (terminal Linux + terminal ternario)

Que el usuario pueda alternar entre el shell Linux y el shell ternario:

```
tritos> modo linux
astrid@pc:~$ ls
...

astrid@pc:~$ modo ternario
tritos> conv 255
...
```

**Falta**: integración entre ambos mundos.

## Lo mínimo viable educativo (MVE)

Si quieres algo **usable en clase mañana**, necesitas:

1. **REPL ternario** con operaciones básicas
2. **Conversor** binario ↔ ternario ↔ base 60
3. **Tutorial** con 5 lecciones
4. **Visualizador** de operaciones paso a paso

Con eso, un profesor puede dar una clase de 1 hora sobre computación ternaria.
