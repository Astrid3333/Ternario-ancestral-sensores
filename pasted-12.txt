| Capa | Tipo | Dónde corre |

## Cómo integrarlo (3 opciones)

### Opción A: Cliente MCP en Python (la más fácil)

Tritos GUI ya está en Python. Añade un módulo que hable con octave-mcp:

```python
# tritos_mcp_client.py
import subprocess, json

class OctaveMCP:
    def __init__(self, server_path="~/octave-mcp/server.py"):
        self.proc = subprocess.Popen(
            ["python3", server_path],
            stdin=subprocess.PIPE,
            stdout=subprocess.PIPE,
            text=True
        )

    def call(self, tool, params):
        request = {
            "jsonrpc": "2.0",
            "id": 1,
            "method": "tools/call",
            "params": {"name": tool, "arguments": params}
        }
        self.proc.stdin.write(json.dumps(request) + "\n")
        self.proc.stdin.flush()
        response = self.proc.stdout.readline()
        return json.loads(response)
```

Uso desde Tritos GUI:
```python
mcp = OctaveMCP()
result = mcp.call("ternary_arithmetic_tool", {"mode": "add", "a": 1, "b": -1})
print(result)  # 0
```

**Ventaja**: funciona **hoy mismo**.
**Desventaja**: solo desde la GUI, no desde el kernel bare-metal.

### Opción B: Servidor MCP persistente + cliente ligero

En vez de lanzar octave-mcp cada vez, lo dejas corriendo como **servicio**:

```bash
# Arrancar octave-mcp como servidor TCP
python3 ~/octave-mcp/server.py --tcp --port 8765
```

Y desde Tritos GUI:
```python
import socket, json

def call_mcp(tool, params):
    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.connect(("localhost", 8765))
    request = {"jsonrpc": "2.0", "id": 1, "method": "tools/call",
               "params": {"name": tool, "arguments": params}}
    sock.sendall((json.dumps(request) + "\n").encode())
    response = sock.recv(65536)
    return json.loads(response)
```

**Ventaja**: sin overhead de arrancar Python cada vez.
**Desventaja**: hay que modificar `server.py` para modo TCP.

## Lo que puedes integrar HOY (sin modificar nada)

### 1. Desde la GUI GTK3

Añade un panel "Matemática" a `tritos_gui.py` que llame a octave-mcp:

```python
# En tritos_gui.py
import subprocess, json

def mcp_call(tool, params):
    req = {"jsonrpc":"2.0","id":1,"method":"tools/call",
           "params":{"name":tool,"arguments":params}}
    p = subprocess.run(
        ["python3", "~/octave-mcp/server.py"],
        input=json.dumps(req)+"\n",
        capture_output=True, text=True, timeout=30
    )
    return json.loads(p.stdout.split("\n")[0])
```

### 2. Desde el terminal Linux

```bash
# Llamar directamente a octave-mcp
echo '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"ternary_arithmetic_tool","arguments":{"mode":"add","a":1,"b":-1}}}' | python3 ~/octave-mcp/server.py
```

### 3. Desde scripts de Tritos

```bash
#!/bin/bash
# script_tritos.sh
mcp() {
    echo "{\"jsonrpc\":\"2.0\",\"id\":1,\"method\":\"tools/call\",\"params\":{\"name\":\"$1\",\"arguments\":$2}}" | \
    python3 ~/octave-mcp/server.py | \
    jq -r '.result.content[0].text'
}

mcp ternary_arithmetic_tool '{"mode":"add","a":1,"b":-1}'
```
