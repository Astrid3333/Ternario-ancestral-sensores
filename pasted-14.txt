### 2. Integrarlos en Tritos

```python
# tritos_lab/blender_integration.py
import subprocess

def render_blender(archivo, salida):
    subprocess.run([
        "blender", "--background", archivo,
        "--render-output", salida,
        "--render-frame", "1"
    ])

def simular_unreal(proyecto):
    subprocess.run([
        "UnrealEditor-Cmd", proyecto,
        "-run=pythonscript", "-script=sim.py"
    ])
```

### 3. Llamarlos desde la GUI

```python
# En tritos_gui.py
def boton_blender_clicked(self, widget):
    render_blender("/tmp/escena.blend", "/tmp/render.png")

def boton_unreal_clicked(self, widget):
    simular_unreal("/tmp/proyecto.uproject")
```
