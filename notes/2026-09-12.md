### Kernel v4.2 — GDT + Paging + Syscalls + User Shell + Window Manager (2026-09-17)

**Componentes implementados:**
- GDT: 6 segments (null, kernel code/data, user code/data, TSS) — `boot/gdt_flush.asm` + `src/gdt.c`
- Paging: 4MB identity mapped, page fault handler — `src/paging.c`
- Syscalls: 32 via int 0x80 (exit, read, write, open, close, fork, exec, mmap, etc.) — `src/syscalls.c`
- ELF loader: 32-bit ELF executable loader — `src/elf.c`
- libc completa: printf/sprintf/sscanf, ctype, qsort, strtok — `src/libc_full.c`
- Framebuffer: pixel/line/rect/circle/char/string — `src/framebuffer.c`
- Mouse: PS/2 driver with IRQ12 — `src/mouse.c`
- User Shell: Ring 3, 18 builtins via syscalls — `src/shell_user.c`
- Window Manager: 16 windows, drag, min/max/close, taskbar — `src/window.c`

**Fixes importantes:**
- IDT must be installed BEFORE GDT (page faults crash without IDT)
- serial_putc mirror must be enabled from start for debug
- Removed duplicate num_to_str from kernel.c (now static inline in ternary.h)

**Kernel size:** 148KB ELF (was 141KB before process management)

### Kernel v4.3 — Real Process Management (2026-09-17)
- Process Control Block (PCB): 32 slots, PID, state, registers, memory, FDs
- States: UNUSED, READY, RUNNING, BLOCKED, ZOMBIE, WAITING
- Context switch: save/restore registers, EFLAGS (boot/context_switch.asm)
- fork(): duplicate process, copy registers
- exec(): load ELF from filesystem, replace memory image
- wait(): wait for child process (any or specific PID)
- exit(): terminate process, cleanup FDs, mark as zombie
- Scheduler: round-robin with real processes
- Shell commands: proc list/ps, proc create, proc kill <pid>, proc test
