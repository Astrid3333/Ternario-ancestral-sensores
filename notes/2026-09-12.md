### Redirection Fix (05:15)
**Problem:** `echo hola > file` created empty file. `cat file` showed nothing.
**Root cause:** Builtins ran in parent process; `dup2()` doesn't affect `printf` buffering.
**Fix:** All commands fork (child runs builtin, parent waits). `cmd_echo` uses `write()` instead of `printf`. `cmd_cat` uses raw `read()`/`write()`.
**Result:** `echo > file`, `echo >> file`, `cat`, `ls | head -3 | wc -l`, `alias g=ls` + `g / | head -2` all work correctly.
**Commit:** `1e77547` — pushed.

### Alias Expansion Fix
**Problem:** `alias ll=ls -la` lost `-la` due to tokenizer splitting on spaces.
**Fix:** `alias`/`unalias` handled in `parse_and_run` before tokenization. Alias expansion uses `strchr(line, ' ')` to find first word boundary, expands, and passes full expanded string to pipe/chain splitting.
**Result:** `alias ll=ls -la` + `ll /tmp | head -5` works.

### && || Fix + New Commands (05:30)
**Problem:** `&&` ran both sides regardless of exit status. `||` same.
**Fix:** `run_single` returns exit status from `waitpid`. `parse_and_run` returns `int`. `&&` checks `left == 0`, `||` checks `left != 0`.
**Root cause:** All builtins returned `void`; child always `_exit(0)`. Fixed `cmd_ls` to return `int`, child dispatch uses `builtin_rc`.
**New commands:** `mkdir`, `mv`, `cp`, `bg`.
**Size:** 60KB.
**Commit:** `20fc222` — pushed.
